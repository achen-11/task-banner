### 2️⃣ 导入时识别摘要

#### 实现思路

##### A. Markdown 格式设计
```markdown
<!-- task-id: xxx -->

**状态：** 已完成
**优先级：** 中

**任务摘要：** 实现了用户登录功能，支持账号密码和第三方登录

**任务描述：**

- [x] 实现登录 API
- [x] 添加前端登录组件

**实现细节：**
- 修改文件：backend/src/api/auth.ts
- 使用 JWT 进行身份验证
- ...
```

##### B. 解析逻辑（伪代码）
```typescript
function parseSingleTask(content: string, projectId: string, taskId: string) {
  const task = {
    _id: taskId,
    projectId,
    title: '',
    status: 'todo',
    priority: 'medium',
    content: '',
    summary: ''  // 新增：任务摘要
  }

  // 解析标题
  const titleMatch = content.match(/^#{1,6}\s+(.+)$/m)
  if (titleMatch) task.title = titleMatch[1].replace(/^\d+\.\s*/, '').trim()

  // 解析状态
  const statusMatch = content.match(/\*\*状态：?\*\*\s*(.+)$/m)
  if (statusMatch) {
    const statusText = statusMatch[1].trim()
    if (statusText.includes('完成')) task.status = 'completed'
    else if (statusText.includes('进行')) task.status = 'in_progress'
    else task.status = 'todo'
  }

  // 🆕 解析任务摘要
  const summaryMatch = content.match(/\*\*任务摘要：?\*\*\s*(.+?)(?:\n|$)/m)
  if (summaryMatch) {
    task.summary = summaryMatch[1].trim()
  }

  // 解析任务描述（排除摘要）
  const descMatch = content.match(/\*\*任务描述：?\*\*\s*([\s\S]+?)(?=\n\*\*|$)/m)
  if (descMatch) {
    let desc = descMatch[1].trim()
    // 移除摘要行（如果在描述中）
    desc = desc.replace(/\*\*任务摘要：?\*\*.*?\n/g, '')
    task.content = desc
  }

  return task
}
```

#### 可行性：✅ 高度可行
- 修改位置：`frontend/src/utils/export.ts` 中的 `parseSingleTask` 函数
- 技术难度：低（正则匹配）
- 工作量：30 分钟
- 风险：低（向后兼容，旧格式也能正常解析）

## ⚠️ 潜在问题和解决方案

### 问题 1：AI 不按格式添加摘要
**场景**：AI 忘记添加"任务摘要: xxx"，或格式不对

**解决方案**：
1. 在提示词中强调格式（加粗、示例）
2. 导入时如果没有摘要，使用智能摘要作为 fallback
3. 导入确认弹窗显示警告："未检测到任务摘要，已自动生成"

```typescript
if (!task.summary) {
  // 自动生成摘要
  task.summary = generateContentSummary('', task.content)
  task.summaryAutoGenerated = true  // 标记为自动生成
}
```

### 问题 2：摘要质量参差不齐
**场景**：AI 生成的摘要太长/太短/不准确

**解决方案**：
1. 在导入确认弹窗，用户可以直接编辑摘要
2. 提示词中给出清晰的示例和规范
3. 添加字数限制（20-50 字）

### 问题 3：旧任务没有摘要
**场景**：历史任务活动没有 summary 字段

**解决方案**：
```typescript
const getActivityDisplayContent = (activity: Activity) => {
  if (activity.summary) {
    return activity.summary  // 新记录有摘要
  } else {
    return generateSmartSummary(activity)  // 旧记录智能生成
  }
}
```

### 问题 4：非 content 字段变更没有摘要
**场景**：状态、优先级变更等没有摘要

**解决方案**：
- 这些字段使用智能摘要（前端生成）即可
- 不需要 AI 干预，因为很简单："将状态从 A 改为 B"
