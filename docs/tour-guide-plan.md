# 漫游式引导功能规划

## 一、引导目标
帮助新用户快速了解任务管理系统的核心功能和操作流程。

## 二、引导步骤规划

### 阶段一：首页引导（首次访问）
1. **欢迎介绍**
   - 目标元素：首页欢迎区域
   - 内容：欢迎使用任务管理系统，介绍系统核心功能
   - 位置：首页顶部

2. **侧边栏导航**
   - 目标元素：侧边栏
   - 内容：介绍左侧导航栏的主要功能入口
   - 位置：侧边栏

3. **首页统计卡片**
   - 目标元素：首页统计卡片区域
   - 内容：介绍任务统计、完成率等关键指标
   - 位置：首页

4. **快捷操作**
   - 目标元素：首页快捷操作面板
   - 内容：介绍快速创建项目、任务等快捷入口
   - 位置：首页

### 阶段二：核心功能引导
5. **我的任务**
   - 目标元素：侧边栏"我的任务"入口
   - 内容：介绍如何查看和管理分配给自己的任务
   - 位置：侧边栏

6. **消息通知**
   - 目标元素：侧边栏"消息"入口
   - 内容：介绍消息通知功能，接收任务更新
   - 位置：侧边栏

7. **项目管理**
   - 目标元素：侧边栏"Projects"入口
   - 内容：介绍如何查看和管理项目
   - 位置：侧边栏

8. **创建项目**
   - 目标元素：侧边栏"创建项目"按钮
   - 内容：介绍如何创建新项目
   - 位置：侧边栏

### 阶段三：高级功能引导（可选，在项目页面内）
9. **全局搜索**
   - 目标元素：顶部搜索框或快捷键提示
   - 内容：介绍使用 Cmd+K 进行全局搜索
   - 位置：顶部导航

10. **项目视图切换**
    - 目标元素：项目页面的 Tab 切换
    - 内容：介绍列表视图、看板视图等不同视图
    - 位置：项目页面

11. **任务创建**
    - 目标元素：项目页面的"新建任务"按钮
    - 内容：介绍如何创建任务
    - 位置：项目页面

## 三、引导触发机制

1. **首次访问自动触发**
   - 检测 localStorage 中是否有 `tour_completed` 标记
   - 首次访问（无标记）时自动开始引导
   - 引导完成后设置标记

2. **手动触发**
   - 在用户菜单或设置中添加"重新开始引导"选项
   - 允许用户随时重新查看引导

3. **跳过机制**
   - 每个步骤都提供"跳过"按钮
   - 提供"跳过全部"选项

## 四、技术实现

### 使用 Element Plus Tour 组件
- 组件：`el-tour`
- 优势：与项目 UI 框架一致，无需额外依赖
- 配置：通过 `steps` 配置引导步骤

### 引导步骤配置结构
```typescript
interface TourStep {
  target: string | HTMLElement  // 目标元素选择器或 DOM
  title: string                 // 标题
  description: string           // 描述
  placement?: 'top' | 'bottom' | 'left' | 'right'  // 位置
  showSkip?: boolean            // 是否显示跳过按钮
}
```

### 状态管理
- 使用 Pinia store 管理引导状态
- 使用 localStorage 持久化完成状态
- 支持重置引导状态

## 五、引导内容优化

1. **内容简洁明了**
   - 每个步骤只介绍一个核心功能
   - 使用通俗易懂的语言
   - 避免技术术语

2. **视觉引导**
   - 高亮目标元素
   - 使用箭头指向
   - 遮罩其他区域

3. **交互友好**
   - 支持上一步/下一步导航
   - 显示进度指示
   - 提供跳过选项

## 六、实现优先级

### 高优先级（必须实现）
1. 侧边栏导航介绍
2. 首页统计卡片
3. 我的任务入口
4. 项目管理入口
5. 创建项目按钮

### 中优先级（建议实现）
6. 消息通知入口
7. 全局搜索功能
8. 快捷操作面板

### 低优先级（可选实现）
9. 项目视图切换
10. 任务创建流程
11. 高级功能介绍
