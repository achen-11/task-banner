## 🎯 核心目标
基于您的反馈，专注实现最有价值的核心功能，避免过度设计。

## 📊 页面布局（简化版）

### 1. 顶部统计概览区域
- **任务统计卡片**：
  - 总任务数
  - 待办任务数
  - 进行中任务数
  - 今日到期任务数（橙色警示）
  - 逾期任务数（红色警示）
- **快捷操作按钮**：
  - 快速创建任务
  - 导出任务列表

### 2. 多维度筛选器区域（保留核心筛选）
- **项目筛选**：多选下拉框，支持搜索
- **状态筛选**：待办、进行中、已完成、审核中
- **优先级筛选**：低、中、高
- **时间筛选**：今日到期、本周到期、本月到期、逾期任务

### 3. 视图切换（只实现两个核心视图）
- **列表视图**：传统表格展示（主视图）
- **看板视图**：按状态分列的卡片展示

### 4. 任务列表主体
- **列表视图**：支持排序、批量选择、快速编辑状态
- **看板视图**：支持拖拽操作，状态自动更新

### 5. 快速操作侧边栏（仅批量操作）
- **选中任务统计**
- **批量操作**：
  - 批量修改状态
  - 批量设置优先级
  - 批量导出

## 🚀 保留的核心功能

### 4. 移动端适配（基础版）✅

export const useUserTasksStore = defineStore('userTasks', () => {
  const tasks = ref<Task[]>([])

  const stats = ref<UserTasksStats>()
