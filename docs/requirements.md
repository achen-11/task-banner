# Task Banner - 项目需求文档

## 1. 项目概述

### 1.1 项目背景
个人拥有 Claude Pro 账号，但工作时间段使用率较低。为了充分利用 Token 配额，需要一个任务管理系统来提前准备好项目需求，并能快速导出为 Markdown 格式供 Claude 执行。

### 1.2 项目目标
- 管理多个个人项目的任务进度
- 提供直观的任务看板视图
- 快速将任务导出为结构化的 Markdown 需求文档
- 优化 Claude Pro 的使用效率

### 1.3 目标用户
个人开发者，管理多个并行的个人项目

## 2. 功能需求

### 2.1 项目管理

#### 2.1.1 项目 CRUD
- **创建项目**
  - 项目名称（必填）
  - 项目描述（可选）
  - 项目状态：进行中、已完成、已暂停
  - 技术栈标签（多选）
  - 创建时间（自动）

- **编辑项目**
  - 修改项目基本信息
  - 更新项目状态

- **删除项目**
  - 删除前二次确认
  - 级联删除项目下所有任务（可选：移至归档）

- **项目列表**
  - 显示所有项目卡片
  - 显示项目任务统计（总数/完成数）
  - 项目筛选和搜索

### 2.2 任务管理

#### 2.2.1 任务 CRUD
- **创建任务**
  - 任务标题（必填）
  - 任务描述（支持 Markdown，必填）
  - 任务状态：待办、进行中、已完成、已发送AI、需优化
  - 优先级：低、中、高、紧急
  - 标签（自定义，支持多个）
  - 预计工作量（可选，如：2小时、1天）
  - 截止日期（可选）
  - 技术要点（可选，数组形式）
  - 参考链接（可选，数组形式）
  - 创建时间（自动）

- **编辑任务**
  - 内联编辑标题
  - 弹窗编辑详细信息
  - Markdown 预览功能

- **删除任务**
  - 单个删除
  - 批量删除（多选）

- **任务排序**
  - 拖拽排序
  - 手动设置优先级排序

#### 2.2.2 任务操作
- **状态流转**
  - 快速切换任务状态
  - 状态变更记录历史

- **任务标记**
  - 标记为"已发送AI"
  - 标记为"需要调整"

- **任务复制**
  - 快速复制任务作为模板

### 2.3 视图模式

#### 2.3.1 看板视图（Kanban）
- 按状态分列展示：待办、进行中、已完成、已发送AI、需优化
- 支持拖拽在列之间移动任务
- 每列显示任务数量
- 列宽自适应

#### 2.3.2 列表视图
- 表格形式展示所有任务
- 支持按列排序（优先级、状态、创建时间、截止日期）
- 内联快速编辑
- 批量操作工具栏

#### 2.3.3 项目分组视图
- 按项目分组展示任务
- 折叠/展开项目组
- 显示项目进度条

### 2.4 导出功能（核心特色）

#### 2.4.1 单任务导出
- 一键导出单个任务为 Markdown
- 导出内容包含：
  - 任务标题
  - 项目上下文
  - 技术栈信息
  - 任务详细描述
  - 技术要点
  - 参考链接
  - 预期输出

#### 2.4.2 批量导出
- 选择多个任务批量导出
- 按优先级或自定义顺序导出
- 生成统一的需求文档

#### 2.4.3 导出模板
- 预设模板：
  - 标准需求模板
  - Bug 修复模板
  - 功能开发模板
  - 代码审查模板
- 自定义模板功能
  - 使用占位符（如 `{{title}}`, `{{description}}`, `{{tech_stack}}`）
  - 模板预览

#### 2.4.4 导出操作
- 一键复制到剪贴板
- 下载为 .md 文件
- 导出历史记录（最近10次）

#### 2.4.5 导出格式示例
```markdown
# 任务需求：{{task_title}}

## 项目信息
- 项目名称：{{project_name}}
- 技术栈：{{tech_stack}}

## 任务描述
{{task_description}}

## 技术要点
{{technical_points}}

## 参考资料
{{reference_links}}

## 预期输出
{{expected_output}}

## 优先级
{{priority}}
```

### 2.5 搜索与筛选

#### 2.5.1 全局搜索
- 搜索任务标题和描述
- 实时搜索结果高亮

#### 2.5.2 高级筛选
- 按项目筛选
- 按状态筛选
- 按优先级筛选
- 按标签筛选
- 按日期范围筛选
- 组合筛选条件

### 2.6 数据管理

#### 2.6.1 数据持久化
- 使用 IndexedDB 本地存储
- 自动保存（防抖机制）
- 离线可用

#### 2.6.2 数据导入/导出
- 导出所有数据为 JSON（备份）
- 从 JSON 导入数据（恢复）
- 数据清理功能

### 2.7 辅助功能

#### 2.7.1 任务模板
- 预设常用任务模板
  - API 开发
  - UI 组件开发
  - Bug 修复
  - 测试用例
  - 文档编写
- 从现有任务创建模板

#### 2.7.2 统计面板
- 项目总览
  - 任务总数
  - 完成率
  - 进行中任务数
  - 已发送AI任务数
- 可视化图表
  - 任务状态分布（饼图）
  - 项目进度对比（柱状图）
  - 任务完成趋势（折线图）

#### 2.7.3 快捷键
- `Ctrl/Cmd + N`：新建任务
- `Ctrl/Cmd + K`：全局搜索
- `Ctrl/Cmd + E`：导出选中任务
- `Ctrl/Cmd + /`：显示快捷键帮助
- `Delete`：删除选中任务
- `Esc`：关闭弹窗

## 3. 技术栈

### 3.1 前端框架
- **Vue 3** (Composition API + `<script setup>`)
- **TypeScript** (类型安全)
- **Vite** (构建工具)

### 3.2 UI 框架
- **TailwindCSS** (原子化 CSS)
- **ElementPlus** (组件库)
- **unplugin-icons** (图标解决方案)

### 3.3 状态管理
- **Pinia** (全局状态管理)

### 3.4 数据存储
- **Dexie.js** (IndexedDB 封装库)

### 3.5 Markdown 处理
- **markdown-it** (Markdown 解析)
- **@vueup/vue-quill** 或 **@toast-ui/editor** (Markdown 编辑器)

### 3.6 拖拽功能
- **VueDraggable** 或 **@vueuse/core** 的 `useDraggable`

### 3.7 工具库
- **VueUse** (常用组合式函数)
- **dayjs** (日期处理)
- **copy-to-clipboard** (剪贴板操作)

### 3.8 代码规范
- **ESLint** + **Prettier** (代码格式化)
- **husky** + **lint-staged** (Git hooks)

## 4. 数据模型

### 4.1 Project（项目）
```typescript
interface Project {
  id: string;                    // UUID
  name: string;                  // 项目名称
  description?: string;          // 项目描述
  status: 'active' | 'completed' | 'paused'; // 项目状态
  techStack: string[];           // 技术栈标签
  createdAt: number;             // 创建时间戳
  updatedAt: number;             // 更新时间戳
}
```

### 4.2 Task（任务）
```typescript
interface Task {
  id: string;                    // UUID
  projectId: string;             // 所属项目ID
  title: string;                 // 任务标题
  description: string;           // Markdown 格式描述
  status: 'todo' | 'in_progress' | 'completed' | 'sent_to_ai' | 'needs_optimization'; // 任务状态
  priority: 'low' | 'medium' | 'high' | 'urgent'; // 优先级
  tags: string[];                // 标签
  estimatedEffort?: string;      // 预计工作量
  dueDate?: number;              // 截止日期时间戳
  technicalPoints?: string[];    // 技术要点
  referenceLinks?: string[];     // 参考链接
  order: number;                 // 排序序号
  createdAt: number;             // 创建时间戳
  updatedAt: number;             // 更新时间戳
}
```

### 4.3 ExportTemplate（导出模板）
```typescript
interface ExportTemplate {
  id: string;                    // UUID
  name: string;                  // 模板名称
  content: string;               // 模板内容（支持占位符）
  isDefault: boolean;            // 是否为预设模板
  createdAt: number;             // 创建时间戳
}
```

### 4.4 ExportHistory（导出历史）
```typescript
interface ExportHistory {
  id: string;                    // UUID
  taskIds: string[];             // 导出的任务ID列表
  templateId: string;            // 使用的模板ID
  content: string;               // 导出的内容
  exportedAt: number;            // 导出时间戳
}
```

## 5. 用户流程

### 5.1 典型工作流程
1. **创建项目** → 输入项目基本信息和技术栈
2. **创建任务** → 在项目中添加多个待办任务，详细描述需求
3. **整理任务** → 设置优先级、标签，拖拽排序
4. **导出任务** → 选择一个或多个任务，一键导出为 Markdown
5. **发送给 AI** → 复制导出内容，粘贴到 Claude 对话
6. **更新状态** → 标记任务为"已发送AI"或"已完成"
7. **追踪进度** → 通过看板视图查看项目进度

### 5.2 页面结构

## 7. 非功能需求

### 7.1 性能要求
- 页面首次加载时间 < 2秒
- 任务列表渲染支持虚拟滚动（100+任务时）
- 操作响应时间 < 100ms

### 7.2 兼容性
- 支持现代浏览器（Chrome、Firefox、Safari、Edge 最新版）
- 不考虑 IE 兼容

### 7.3 可用性
- 界面简洁直观
- 关键操作有明确的视觉反馈
- 错误提示清晰友好

### 7.4 可维护性
- 代码结构清晰，组件化
- 完善的 TypeScript 类型定义
- 核心功能有单元测试

## 8. UI/UX 设计建议

### 8.1 配色方案
- 主色调：蓝色系（专业、高效）
- 辅助色：灰色系（中性背景）
- 状态色：
  - 待办：灰色 `#6B7280`
  - 进行中：蓝色 `#3B82F6`
  - 已完成：绿色 `#10B981`
  - 已发送AI：紫色 `#8B5CF6`
  - 需优化：橙色 `#F59E0B`
  - 紧急：红色 `#EF4444`

### 8.2 布局风格
- 侧边栏：项目导航
- 主区域：任务看板/列表
- 卡片设计：阴影、圆角、悬浮效果
- 响应式设计（优先桌面端）

### 8.3 交互设计
- 拖拽流畅，有视觉反馈
- 点击编辑有明确的焦点状态
- Loading 状态显示（骨架屏）
- Toast 提示操作结果
