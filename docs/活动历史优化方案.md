## 📋 当前问题分析

根据截图 `docs/Images/kb-task/活动历史列表调整.png` 分析，活动历史界面存在以下问题：

### 问题 1：用户显示不友好
- ❌ **现状**：显示用户 `_id`（`311caa24-691f-4c5b-b5c4-60390dd0c360`）
- ❌ **问题**：ID 长度过长，占用大量空间，用户无法识别
- ✅ **应该**：优先显示 `displayName` → `username` → `email` -> `userId`

### 问题 2：布局拥挤
- ❌ **现状**：用户名、内容、时间在同一行横向排列
- ❌ **问题**：三个元素挤在一起，导致文字折行、可读性差
- ✅ **应该**：改为纵向布局，用户名和时间在上，内容在下

### 问题 3：内容显示粗暴（核心问题）
- ❌ **现状 1**：最后一条记录显示完整的技术实现细节（500+ 字）
  ```
  将描述从「- [ ] 通过 cmd+i 导入任务时没有任务活动历史记录...」改为
  「- [x] 通过 cmd+i 导入任务时没有任务活动历史记录...已在 Service 层
  实现完整的任务历史记录功能：1. **创建任务历史记录**...」
  ```

- ❌ **现状 2**：字段变更直接显示完整的旧值和新值
  ```
  将状态从「in_progress」改为「completed」
  ```

- ❌ **问题**：
  - 长内容完全不可读，占用大量垂直空间
  - 无语义化摘要，无法快速理解变更意图
  - 对于 AI 补充的实现细节，应该智能识别并简化显示

## 💡 优化方案对比

### 方案 A：智能摘要 + 可展开详情 ⭐（推荐）

#### 核心思路
- 根据字段类型、内容长度、内容特征，自动生成友好的摘要文本
- 对于被截断的内容，提供「展开」按钮查看详情
- 平衡信息密度和可读性

#### 优点
- ✅ 信息完整：重要信息保留，次要信息可展开查看
- ✅ 可读性强：摘要清晰，快速理解变更意图
- ✅ 灵活性好：支持展开/收起，满足不同场景需求

#### 缺点
- ⚠️ 实现复杂度中等：需要编写摘要生成逻辑
- ⚠️ 需要维护关键词列表

---

### 方案 B：完全隐藏长内容（简洁方案）

#### 核心思路
- 对于长内容字段（如 content），只显示操作类型，不显示具体内容
- 用户需要点击活动项才能查看详情

#### 示例
```
张三  2小时前
更新了任务描述
```

#### 优点
- ✅ 界面极简，无干扰
- ✅ 实现简单

#### 缺点
- ❌ 信息丢失：用户完全不知道改了什么
- ❌ 需要额外操作：必须点击才能看到内容


## 3️⃣ 智能摘要规则设计

### 核心函数

```typescript
/**
 * 生成活动内容摘要
 * @param activity 活动数据
 * @returns 摘要文本
 */
const generateActivitySummary = (activity: Activity): string => {
  const { field, oldValue, newValue, action } = activity

  // 1. 创建事件
  if (action === 'create') {
    return '创建了任务'
  }

  // 2. 删除事件
  if (action === 'delete') {
    return `删除了${getFieldName(field)}`
  }

  // 3. content 字段 - 特殊处理
  if (field === 'content') {
    return generateContentSummary(oldValue, newValue)
  }

  // 4. 其他字段 - 标准格式
  return generateStandardSummary(field, oldValue, newValue)
}
```

### 规则 1：短字段（状态类）

保持现有格式，直接显示完整内容：

| 字段 | 示例 |
|------|------|
| `status` | 将状态从「待办」改为「进行中」 |
| `priority` | 将优先级从「中」改为「高」 |
| `assigneeId` | 将指派人设置为「张三」<br>取消了指派 |
| `dueDate` | 设置截止日期为 12/25<br>取消了截止日期 |
| `progress` | 更新进度为 60% |
| `title` | 将标题从「旧标题」改为「新标题」 |

**实现代码**：
```typescript
const generateStandardSummary = (
  field: string,
  oldValue?: string,
  newValue?: string
): string => {
  const fieldNames: Record<string, string> = {
    title: '标题',
    status: '状态',
    priority: '优先级',
    assigneeId: '指派人',
    dueDate: '截止日期',
    progress: '进度'
  }

  const fieldName = fieldNames[field] || field

  // 特殊处理：设置/取消
  if (!oldValue && newValue) {
    return `设置${fieldName}为「${newValue}」`
  }
  if (oldValue && !newValue) {
    return `取消了${fieldName}`
  }

  // 标准格式
  return `将${fieldName}从「${oldValue}」改为「${newValue}」`
}
```

#### 场景 C：完整实现代码

```typescript
const generateContentSummary = (
  oldValue?: string,
  newValue?: string
): string => {
  const newVal = newValue || ''
  const oldVal = oldValue || ''

  // 1. 检测实现细节
  const DETAIL_KEYWORDS = [
    '实现细节', '修改文件', '技术要点',
    'Service 层', '已在', '函数中',
    '- [ ]', '- [x]', '**修改文件**'
  ]
  const isDetail = DETAIL_KEYWORDS.some(kw => newVal.includes(kw))

  if (isDetail) {
    return '补充了实现细节'
  }

  // 2. 新增描述
  if (!oldVal && newVal) {
    if (newVal.length < 50) {
      return `添加了任务描述：${newVal}`
    } else {
      return `添加了任务描述：${newVal.substring(0, 50)}...`
    }
  }

  // 3. 更新描述
  if (oldVal && newVal) {
    return `更新了任务描述（${newVal.length} 字）`
  }

  // 4. 清空描述
  if (oldVal && !newVal) {
    return '清空了任务描述'
  }

  return '修改了任务描述'
}
```

**交互设计**：


**展开状态**：
```

添加了任务描述：
需要实现用户登录功能，包括账号密码登录、第三方登录（微信、
支付宝、GitHub），并且支持记住登录状态。需要注意安全性，
密码要加密存储，使用 bcrypt 或 argon2。

[收起]
```

**实现代码**：
```typescript
// 状态管理
const expandedActivities = ref<Set<string>>(new Set())

// 切换展开状态
const toggleExpand = (activityId: string) => {
  if (expandedActivities.value.has(activityId)) {
    expandedActivities.value.delete(activityId)
  } else {
    expandedActivities.value.add(activityId)
  }
}

// 判断是否需要展开按钮
const shouldShowExpandButton = (activity: Activity) => {
  if (activity.field !== 'content') return false
  const content = activity.newValue || ''
  return content.length > 50
}

// 获取显示内容
const getDisplayContent = (activity: Activity) => {
  const isExpanded = expandedActivities.value.has(activity.id)

  if (isExpanded) {
    return activity.newValue || ''
  } else {
    return generateActivitySummary(activity)
  }
}
```
