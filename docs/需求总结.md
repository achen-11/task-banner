# 项目融合需求总结

## 一、项目基本信息

**项目名称**: TaskFlow（暂定）
**项目类型**: 多人协作任务管理系统
**技术栈**:
- 前端: Vue 3 + TypeScript + Tailwind CSS
- 后端: Kooboo API
- 数据库: SQLite (k_sqlite_orm)
- 富文本编辑器: Quill.js
- 实时通信: WebSocket

## 二、核心功能模块

### 1. 用户系统
- 用户注册/登录（使用 Kooboo 内置功能）
- 用户个人信息管理
- **不包含团队/组织概念**

### 2. 项目管理
- 创建/编辑/删除项目
- 项目信息：名称、描述、成员
- 项目首页展示：概览/列表/看板/成员四个 Tab

### 3. 任务管理

#### 3.1 任务 CRUD
- 创建任务（快捷创建 + 详细创建）
- 编辑任务（行内编辑 + 抽屉详情）
- 删除任务
- 任务字段：
  - 标题
  - 内容（Quill.js 富文本）
  - 负责人
  - 创建人
  - 截止日期
  - 优先级（低/中/高/紧急）
  - 状态（待办/进行中/已完成/发送给AI/需要优化）
  - 所属模块（支持多级嵌套）
  - 标签（多选）
  - 进度百分比
  - 排序字段

#### 3.2 任务视图
- **列表视图**: Grid 12列布局，支持拖拽排序
  - 任务名称（5列）
  - 负责人（2列）
  - 截止日期（2列）
  - 优先级（1列）
  - 状态（2列）
  - 支持分组显示（可选）：按状态/模块/负责人分组

- **看板视图**: 按状态分列，支持拖拽移动
  - 任务卡片显示：标题、状态、优先级

#### 3.3 任务详情（保留 task-banner 特色）
- 侧边抽屉展示
- 支持快捷键操作
- **迭代历史**: 显示任务的所有修改记录
- **评论功能**: 支持 @提醒

#### 3.4 任务搜索与筛选
- 全局搜索（顶部导航栏）
- 筛选维度：
  - 项目
  - 优先级
  - 状态
  - 截止日期
  - 负责人
  - 模块

### 4. 模块管理（Module）
- 不使用 kb-task 的"区段（Section）"概念
- **支持多级嵌套**
- 模块字段：
  - 名称
  - 颜色标识
  - 父模块 ID（支持嵌套）
  - 排序字段

### 5. 页面结构

#### 5.1 首页（Home）
- 待办任务概览
- 最近访问的项目
- 统计数据
- 快捷操作入口

#### 5.2 我的任务（My Tasks）
- 显示范围：所有项目中分配给我的任务 + 我创建的任务
- 支持视图：列表/看板
- 支持筛选：项目/优先级/状态/截止日期

#### 5.3 消息（Messages）
- 任务分配通知
- 任务状态变更通知
- @提醒通知
- 评论通知

#### 5.4 项目首页
- 顶部项目信息区（支持收起）
  - 项目名称、描述
  - 项目设置按钮
  - 项目成员头像
- Tab 栏切换：
  - 概览：项目统计、最近动态
  - 列表：Grid 表格式任务列表
  - 看板：任务看板视图
  - 成员：项目成员管理

### 6. 导入导出功能（保留 task-banner）
- **导出格式**:
  - JSON: 数据同步
  - XLSX: 数据同步
  - Markdown: 提交给 AI
- **导出范围**: 单个任务/项目所有任务
- **导入功能**: 支持 JSON/XLSX，用于数据迁移

### 7. 快捷键系统（保留 task-banner 所有快捷键）
参考 task-banner 现有快捷键实现

### 8. 实时通信（WebSocket）
- 任务创建/更新/删除的实时推送
- 评论的实时推送
- 通知的实时推送

## 三、UI/UX 设计规范（参考 kb-task）

### 颜色方案
```
背景色：
- 侧边栏：bg-zinc-50
- 主内容：bg-gray-50
- 表头：bg-gray-50
- 卡片/面板：bg-white

边框：
- 主边框：border-gray-200
- 次级边框：border-gray-100

交互状态：
- 悬停：hover:bg-gray-200 (侧边栏菜单)
- 悬停：hover:bg-gray-50 (任务列表)
- 激活：bg-zinc-200
- 选中：bg-gray-100

文字：
- 主文字：text-gray-900
- 次要文字：text-gray-500
- 禁用文字：text-gray-400
```

### 布局规范
- 统一圆角：`rounded-md`
- 过渡动画：`transition-colors duration-200`

## 五、数据迁移方案

### 从 task-banner 迁移数据
1. 使用 task-banner 的导出功能，导出 JSON 数据
2. 编写数据转换脚本，将 JSON 数据转换为新系统格式
3. 通过 API 导入数据到新系统

### 迁移映射关系
```
task-banner.Project -> 新系统.Project
task-banner.Task -> 新系统.Task
task-banner.ChangeLogEntry -> 新系统.TaskHistory
```

## 六、技术要求

### 后端要求
- 使用 Kooboo API 框架
- 使用 k_sqlite_orm 定义数据模型
- **不使用软删除**（直接物理删除）
- RESTful API 设计
- WebSocket 支持

### 前端要求
- Vue 3 Composition API + TypeScript
- Tailwind CSS 样式
- Pinia 状态管理
- Vue Router 路由管理
- Axios 请求封装
- Quill.js 富文本编辑器

### 代码规范
- ESLint + Prettier
- TypeScript 严格模式
- 组件化开发
- 响应式设计
