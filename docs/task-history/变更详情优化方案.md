# 任务变更详情弹窗优化方案

## 当前问题分析

### 现状
当前的变更详情弹窗 (TaskActivity.vue:174-219) 显示：
```
用户信息
---
任务摘要：xxx
---
完整变更内容：
  字段: title
  旧值: 旧标题
  新值: 新标题
```

### 存在的问题
1. **字段名不友好**：显示 `title`、`assigneeId` 等技术字段名
2. **值显示粗糙**：状态显示 `todo`、日期显示时间戳
3. **内容变更难以阅读**：长文本 content 的 before/after 难以看出差异
4. **缺少视觉层级**：所有信息平铺，重点不突出

---

## 优化方案

### 方案 A：基础优化（推荐先实施）

#### 1. 字段名本地化
```typescript
const fieldNames: Record<string, string> = {
  title: '任务标题',
  content: '任务描述',
  status: '状态',
  priority: '优先级',
  assigneeId: '指派人',
  dueDate: '截止日期',
  progress: '进度'
}
```

#### 2. 值格式化
- **状态**：`todo` → `待办`，`in_progress` → `进行中`
- **优先级**：`high` → `高`，`medium` → `中`
- **日期**：时间戳 → `2025/10/26 18:00`
- **用户ID**：查询用户信息显示名称

#### 3. 视觉优化
```html
<div class="field-change">
  <div class="field-name">任务标题</div>
  <div class="change-content">
    <div class="old-value">
      <span class="label">旧值：</span>
      <span class="value">旧标题</span>
    </div>
    <svg class="arrow">→</svg>
    <div class="new-value">
      <span class="label">新值：</span>
      <span class="value highlight">新标题</span>
    </div>
  </div>
</div>
```

**效果预览**：
```
┌─────────────────────────────────┐
│ 任务标题                         │
│ 旧值：旧标题  →  新值：新标题    │
│                         ^^^^     │
│ 状态                             │
│ 旧值：待办    →  新值：已完成    │
└─────────────────────────────────┘
```

## 技术实现参考

### 格式化函数示例
```typescript
const formatFieldValue = (field: string, value: string): string => {
  if (field === 'status') {
    const statusMap = { todo: '待办', in_progress: '进行中', completed: '已完成' }
    return statusMap[value] || value
  }

  if (field === 'priority') {
    const priorityMap = { low: '低', medium: '中', high: '高' }
    return priorityMap[value] || value
  }

  if (field === 'dueDate') {
    return value ? new Date(Number(value)).toLocaleString('zh-CN') : '未设置'
  }

  if (field === 'assigneeId') {
    // 查询用户信息
    const user = getUserById(value)
    return user?.displayName || user?.username || value || '未指派'
  }

  return value || '空'
}
```

```html
          </div>

            <span class="tag">新值</span>
            {{ formatFieldValue(field, newValue) }}
          </div>
        </div>
      </div>
    </div>
  </div>
</el-dialog>
```

## 讨论问题

### Q1. 内容 Diff 是否必要？
- 如果任务描述很少超过100字，可能不需要
- 如果经常有大段文字修改，Diff 很有价值

### Q2. 是否要显示所有字段变更？
- 当前合并逻辑会把多个字段合并
- 弹窗是否显示所有字段，还是只显示用户关心的？

### Q3. 颜色标识的重要性？
- 绿色/红色对色盲用户不友好
- 是否用图标代替颜色？
