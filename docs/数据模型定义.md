# 数据模型定义（K_SQLITE_ORM）

## 说明

本文档定义了 TaskFlow 项目的所有数据模型，使用 K_SQLITE_ORM 进行定义。

**重要**:
- ❌ 不使用软删除（`softDelete: false`）
- ✅ 所有删除操作都是物理删除
- ✅ 使用自动时间戳（`timestamps: true`）

---

## 1. 用户模型 (Users)

```typescript
import { ksql, DataTypes } from './k_sqlite'

export const User = ksql.define(
  'users',
  {
    id: {
      type: DataTypes.Number,
      primaryKey: true,
      autoincrement: true,
      initialValue: 1000
    },
    username: {
      type: DataTypes.String,
      required: true,
      unique: true,
      index: true
    },
    email: {
      type: DataTypes.String,
      required: true,
      unique: true,
      index: true
    },
    password: {
      type: DataTypes.String,
      required: true,
      select: false // 默认查询不包含密码
    },
    avatar: {
      type: DataTypes.String,
      default: ''
    },
    displayName: {
      type: DataTypes.String,
      default: ''
    }
  },
  {
    timestamps: true, // 自动添加 createdAt, updatedAt
    softDelete: false // 不使用软删除
  }
)

export type UserType = {
  _id: string
  id: number
  username: string
  email: string
  password: string
  avatar: string
  displayName: string
  createdAt: number
  updatedAt: number
}
```

## 3. 项目成员模型 (ProjectMembers)

```typescript
export const ProjectMember = ksql.define(
  'project_members',
  {
    id: {
      type: DataTypes.Number,
      primaryKey: true,
      autoincrement: true
    },
    projectId: {
      type: DataTypes.Number,
      required: true,
      ref: 'projects',
      index: true
    },
    userId: {
      type: DataTypes.Number,
      required: true,
      ref: 'users',
      index: true
    },
    role: {
      type: DataTypes.String,
      default: 'member', // owner, admin, member, viewer
      index: true
    },
    joinedAt: {
      type: DataTypes.Timestamp,
      default: () => Date.now()
    }
  },
  {
    timestamps: false, // 不需要自动时间戳，使用 joinedAt
    softDelete: false,
    afterTableCreate() {
      // 创建复合唯一约束：一个用户在一个项目中只能有一个角色
      ksql.execute(
        'CREATE UNIQUE INDEX IF NOT EXISTS idx_project_user ON project_members(projectId, userId)'
      )
    }
  }
)

export type ProjectMemberType = {
  _id: string
  id: number
  projectId: number
  userId: number
  role: 'owner' | 'admin' | 'member' | 'viewer'
  joinedAt: number
}
```

```typescript
      type: DataTypes.Number,
      default: 0 // 0-100
    },

      type: DataTypes.Number,
      default: 0

    softDelete: false
```

## 使用示例

### 初始化数据库（开发模式）

```typescript
// 在应用启动时，所有模型定义会自动创建表（如果启用了开发模式）
import models from './models'

// 检查表结构差异
```
